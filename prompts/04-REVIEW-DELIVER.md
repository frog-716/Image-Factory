# 人工审核与 ZIP 交付

读 AGENTS.md、docs/04-数据契约.md 和 docs/USER-GUIDE.md。AI 可指出视觉疑点，但每张图的结论必须由本人在 `dist/Image Factory.app` 打开的“待我审核”页面明确确认。Codex 不得代点，不得直接写飞书审核表。

给用户的操作路径只有：打开 App → 启动并打开审核工作台 → 待我审核 → 点图看大图 → 通过/退回 → 再确认。退回原因可选。请检查商品形状和颜色、Logo/纹理/结构、背景自然度、抠图边缘、光影、平台用途和禁止内容；Demo 通过只代表演示视觉检查，不允许真实上架或投放。

Engine API 从当前可信上下文绑定图片版本、SHA256、审核人、Runtime 与策略，经 FeishuGateway 写入审核；Runner 只读取 Engine 确认的有效审核。若 App 或 API 不可用，诊断故障，不让用户进入底表补填技术字段。人工尚未检查完时保持 `waiting_review`，不能自补同意。

审核全部完成且 Runner 健康后，在“任务与交付”领取 ZIP；如果仍等待，先只读检查状态和审计，不重复提交审核。用户明确同意部分交付后才允许部分交付。

检查交付清单内 requested_candidates、generated_candidates、delivered_count。候选 6、批准 2 就交付 2，不补副本凑数量。用 ZIP 内容检查和 SHA256 校验确认文件真实存在。

优先给出“任务与交付”的下载入口；必要时再指向任务中的“已批准交付包”附件或实际本地路径。不要把“运行档案”作为最终图片交付包，它包含内部素材、完整提示词和证据。

返工：复制新任务并关联返工来源，根据人工原因修改创意；旧成图和旧审核保留。已批准后要撤回，新增撤回记录；告诉用户此前下载/上架的旧文件仍需人工停用，本脚本不会自动撤回第三方渠道。
