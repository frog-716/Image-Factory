# 人工审核与 ZIP 交付

读 AGENTS.md、docs/04-数据契约.md。AI 可描述视觉问题，真实审核事件必须由人在飞书中填写。禁止用现有 user token 替人写“通过”。

提醒用户到素材画册检查：商品形状和颜色、Logo/纹理/结构、背景自然度、抠图边缘、光影、平台用途和禁止内容。提醒在审核表选择实际成图和本人，填目标 SHA256，填写结论并勾人工确认；通过还需勾商品准确、品牌及渠道检查。

读取真实审核后：

```bash
python -m factory sync-reviews --run 实际RUN
python -m factory export --run 实际RUN
```

人工尚未检查完时停止在待审核，不能自补同意。用户明确同意部分交付后才加 `--allow-partial`。

检查交付清单内 requested_candidates、generated_candidates、delivered_count。候选 6、批准 2 就交付 2，不补副本凑数量。用 ZIP 内容检查和 SHA256 校验确认文件真实存在。

将任务中“已批准交付包”的真实附件指向用户，或给出实际本地路径。不要把“运行档案”作为最终图片交付包，它包含内部素材、完整提示词和证据。

返工：复制新任务并关联返工来源，根据人工原因修改创意；旧成图和旧审核保留。已批准后要撤回，新增撤回记录；告诉用户此前下载/上架的旧文件仍需人工停用，本脚本不会自动撤回第三方渠道。
