# 商品与素材入库

读 AGENTS.md、docs/02-飞书平台搭建.md。目标是让一个真实 SKU 和来源明确的图片进入飞书画册，用户后续能点选使用。

先读取指定 Base 的真实字段结构和已有商品/素材记录，按实际 SKU/资产 ID 查重。不要因搜索片段没看到就断言不存在；按已批准范围完成必要分页。

商品事实来自用户提供的品牌资料、商品档案或已核实的自有店铺数据。商品品牌与店铺品牌分清。没有证据的材质、功能、适龄人群、认证等留空/待确认，不生成营销“事实”。

第一单只选一个商品原图角度。需要背景合成时要求透明原图并让人检查抠图边缘。上传时一条素材一个文件版本，记录来源、授权说明、所属商品和 SHA256。用户未确认授权或事实时只创建草稿，保留“允许用于生图/资料已确认”为 false。

上传附件使用已经验收的 larkcli 专用附件链路；记录实际 file_token，不能把图片 URL 填进附件字段冒充上传。源文件只读取用户明确选择的路径，不扫描电脑其他目录。先前模糊提出的拼多多抓图需求不构成绕过登录/验证码或搜集其他品牌图片的许可。

可由用户直接在飞书上传；你负责检查是否一图一记录、SKU 归属一致、源图真的存在、授权字段齐全。商品表的预览照片只作浏览，生产关联到“默认商品素材”。

风格参考、场景参考与商品原图分开。参考图只告诉模型颜色、光线、构图，不自动成为商品事实。其他商家的详情图不得因为公开可见就标记授权。

输出：商品记录 ID、原图资产 ID、可用参考列表、缺少的事实/授权确认。引导用户在飞书完成确认，再进入生产阶段。包内 DEMO 和连接探针必须保留示例标志，不进入真实生产。
