# 使用登记、真实反馈与下一轮创意

先读 AGENTS.md、docs/04-数据契约.md。发布由用户操作，本阶段没有电商/广告账户自动写入许可。

用户实际使用批准图后，协助在“上架记录”建立使用 ID，精确关联图片资产和 SHA256、渠道、账户、版位、广告或页面 ID、开始/结束时间、对照说明。用户确认实际上线后才勾确认。不得把一个 SKU 的全店指标归给某张图。

读取用户提供的渠道原始导出，保留原文件/截图到对应上架证据，再转换为 templates/metrics.csv。展示字段映射：哪一列是曝光、点击、订单；日期和时区；是否单图/单广告统计；订单归因口径。无法证明单图归属时停止该行导入并说明，不能平均分摊。

真实导出标记 platform_export；有截图/原件可核对的人工转录标记 verified_manual。包内模拟数据只能留 demo，不得改标签变成真实。

执行 import-metrics。更正时仅在用户明确允许后执行下一 revision，保留旧值和原文件。metrics-summary 只返回最新修订版，比较时防止把旧版重复累计。

分析输出：样本量、时间窗、渠道和口径、当前观察、主要混杂因素，以及下一轮 2 至 3 个具体创意。点击高不证明图片导致销量提升；1000 曝光的提醒阈值不等于显著性测试。不得自动贴“爆款”、自动调投放预算或改商品事实。

新创意落实为新任务或新流程版本。保持商品事实层稳定，风格/背景/构图等可实验因素明确记录。
