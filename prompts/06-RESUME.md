# 中断后的安全恢复

先读 AGENTS.md、docs/06-验收与恢复.md。不要依据上一段聊天记忆重新开始生成。

查看当前配置指向的 Base、实际状态目录和 `python -m factory status`。检查任务运行 ID、最新档案 SHA256、各槽位状态和 unknown_remote_writes。

对 STARTED 无回执的槽位，先检查当前原生工具会话是否已经生成实际文件。找到则核对尝试 ID、素材和 Prompt 后登记；找不到则说明可能已执行/可能消耗额度，请用户对该槽位决定是否接受重试风险。没有明确授权不得 retry-slot。

对远端写入 unknown，先只读查同一业务 ID/文件哈希命名，允许正常可见性延迟。找到结果就让程序对账。确定未成功且获得用户承担风险的确认后才 resolve-effect，再执行原命令。不能把所有 unknown 一键清空。

本机账本丢失时只恢复对应 Base 最新检查点。通过真实附件 token 下载，核对最新档案 SHA256 后在新的空 --state 中 restore。已派发状态必须保留。没有可核实最新档案就停下来报告，不能恢复旧包然后重新生图。

任务输入被改导致 guard 失败时，不改快照，新增任务/版本继续。审批记录被改或删除时先核对审计历史、恢复原事件并新增更正，不能删除本地 reviews_seen。

恢复后汇报：可继续槽位、已完成槽位、仍不确定槽位和预算。禁止承诺后台等待额度自动恢复。
