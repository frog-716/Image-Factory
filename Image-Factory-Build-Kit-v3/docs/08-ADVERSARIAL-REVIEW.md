## 修正后的边界

参考 Runtime 不验证真实飞书身份，不能作为对抗本机恶意管理员的安全边界。
同账号 user 模式下，Agent 理论上可获得人工拥有的权限，提示词不能构成强隔离。
团队上线前配置独立执行身份或更强权限控制，当前单人试用须披露。

文件 SHA 能证明字节一致，不能证明商品真实、品牌授权、美观或商业效果。
生成过程留有回执不代表可逐像素复现，Prompt 和随机生成不可混称确定性重现。
未知模型名写 not_reported；原生订阅成本未知写 null，不写免费或零成本。

## 关键 live 攻击测试

1. 同一任务连点提交两次，只生成一个 Run revision。
2. Worker 已产图但进程退出，重启使用旧产图，不再次生图。
3. 附件绑定完成但响应超时，读回 hash 正确就复用。
4. 候选通过后换图片/撤回审批，导出拒绝或明确新审核。
5. 任务完成后同步飞书失败，只重放状态 outbox，不重新调用 Producer。
6. 修改已发布 Prompt 不影响已冻结的旧任务。
7. 关闭开发 Thread，再启动 Runtime 能完成当前节点之后的任务。
8. 从正式统计入口查询，Demo、未知 mode、模拟指标全部不可见。

所有失败保存检查点。不得为“全绿”删保护、补假数据、篡改人审或把没跑的项标 PASS。
