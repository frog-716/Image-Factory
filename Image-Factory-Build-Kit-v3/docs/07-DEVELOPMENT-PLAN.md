# 07 开发任务与 Sol/Luna 协作

## 角色只用于开发

Sol：架构、接口权威、任务分解、合并、live 变更批准、对抗审查和最终验收。
Luna：边界清晰的开发/测试/文档任务。返回证据给 Sol，不直接指挥生产引擎。
复核者：尽量不由同一子代理同时实现和宣布无缺陷；至少 Sol 独立复核变更和关键测试。

每个子任务必须包含 task_id、依赖、可改文件、禁止文件、输入契约、验收命令、证据路径。
共享文件只有一位 owner；Luna 不直接使用 lark-cli 写 live Base，不设置预算和审批。

## 阶段依赖图

```text
B0 盘点/备份/能力核实
  ↓
B1 原生节点垂直切片与回执协议
  ↓
B2 独立 Runtime 持久化调度/恢复
  ├→ B3 飞书交互与审核语义
  └→ B4 童鞋真实素材/Prompt/合成
          ↓
B5 审核/ZIP/反馈/状态同步
          ↓
B6 对抗性审查 + 故障/恢复验收
          ↓
B7 运行入口与小白使用手册交接
```

### B0：盘点现役工程

Sol 定边界，Luna 只读采集接口和测试基线。保护已有 8 表与 Gateways。
输出 baseline、reuse-map、capabilities、backup evidence、taskboard。
验收：本机实际路径正确；现役测试结果记录；备份可读；未知写入状态清楚。
不是 Git 工作树时标记事实，不能用“尾随空白检查”声称 git diff 完成。

### B1：最早证明 Codex 是可调用节点

Luna 实现 request/receipt 结构和沙箱文件校验，Sol 管一次真实调用。
优先用获授权的透明童鞋源图同时验证本机生图、输出文件、实际模型记录与能力等级。
要证明 Runtime 能创建节点请求、接收真实文件、保存证据、重启后不再调用同一单。
若 headless native image 不可用，标记阻断并继续无依赖开发，禁止无限翻工具重试。
不要先做完所有页面才发现原生 Worker 不能被程序调用。

### B2：独立 Runtime

复用现役账本，只建立一个执行权威。固定顺序节点、冻结输入、原子领取、预算和 unknown 协调。
参考 `reference/ifkit_ref/`，按缺口吸收代码思想；不整体替换 existing engine。
实现 runner start/status/stop 或等效入口，OS 单实例锁、进程重启恢复、状态投影 outbox。
关闭开发对话后任务仍能等待和继续。运行 Worker 的权限不得扩散成开发工程师权限。

### B3：飞书交互与审核

四入口，任务表单能选商品/场景/组件，至少 3 个样例组合。
Demo 审核用独立语义；必要最小新增字段先列 dry-run，备份并受控迁移。
已有页面/仪表盘不盲重建；单张表聚合能力不够时从 Runtime 汇总投影，不用数历史审核行。
每次状态变更包含 run_revision，重复同步跳过，过期版本拒绝覆盖。

### B4：童鞋真素材链

生成源图/白底派生/3 背景/3 合成；独立单图，不拼图，不使用旧广告图冒充原始商品。
Prompt 组件和步骤在飞书可点选，执行时冻结；AI 创意节点受结构约束。
图像风格评审要看实际图，文件可解码不足以判定美观。
本次 source1+背景3+最多2修正属于同一 6 次授权，B1 的源图直接复用。

### B5：完整管理与反馈

审核来自真实用户。全部有效审核完成后自动导出批准图；全部驳回就 no_delivery。
ZIP 两次 hash 校验，集合等于批准集合；状态同步不能停留待审核。
模拟 Usage/指标来源可追溯，重复导入 existing，正式统计明确排除 demo。
人无需再发一篇提示词触发导出。人工决定完成后 runner 自己接着处理。

### B6：对抗性审查

按 docs/08 的风险逐项给 evidence/fix/test。故障注入主要离线；真实 Base 不做无边界破坏测试。
关键代码改后运行受影响测试，阶段结束跑全量；禁止每改一行就全量耗尽预算。
live 最少证明：真实图附件、审核、ZIP round-trip、指标幂等、重启不重画。

### B7：交接

生成真正可执行的 `启动图片工厂.command` 或等效一步入口，包含环境探测、单实例锁和错误提示。
不要在最终操作教程里让用户手写 SQLite、hash、CLI 参数或 worker JSON。
提供 `暂停`、`状态`、`继续`、回滚步骤，且没有远程控制/公网端口默认暴露。
输出截图或录屏证据、架构说明、接口、变更清单、测试、使用文档和已知限制。

## 停止条件不是每个里程碑

有权限就继续。只在人工决策、预算/模型能力缺口、真实远端状态不明或必须扩大影响范围时提问。
发生局部错误先调查，修复后自动回归到检查点，不把同一长恢复提示词反复交给用户。
完成目标或遇到真实阻断时提供可恢复交接。
