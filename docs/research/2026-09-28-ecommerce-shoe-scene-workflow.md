# 电商鞋图怎样自然进入真实场景

- 调研日期：2026-09-28
- 范围：只查官方图像产品文档、官方工程资料和原始研究论文；未调用图片工具，未接触运行中的 Image Factory 或飞书数据。
- 目的：解释“鞋像贴纸、场景假”的成因，并给后续鞋类场景图流程提供可检查的方法。不是模型排行榜，也没有在本轮生成或验证新图。

## 结论先说

用户指出的问题成立：**把鞋抠出来，缩放后贴到一张另行生成的背景上，不等于完成了真实的商品场景摄影。** 本仓库目前记录的默认方式正是“模型生成背景，程序再放入透明商品图”；架构文档也明确承认它不保证自然接触阴影、透视或审美。[项目当前边界](../01-架构与边界.md) 因此，继续只改背景提示词，解决不了鞋子悬浮、光色不合、比例不对和摆放像拼装的问题。这是结合现有流程与用户反馈作出的**根因推断**。

计算机视觉研究把自然合成拆成几件事：透视/几何适配、颜色与光线协调、阴影生成；单纯复制粘贴会缺少这些处理。[CVPR《ObjectStitch》](https://openaccess.thecvf.com/content/CVPR2023/html/Song_ObjectStitch_Object_Compositing_With_Diffusion_Model_CVPR_2023_paper.html) 现在的编辑模型能用商品图和场景图共同生成或编辑，也能做局部遮罩编辑，但“参考图”和“遮罩”都不是商品百分百不变的保证。[OpenAI 图像生成 API 文档](https://developers.openai.com/api/docs/guides/image-generation) [OpenAI 图像编辑提示指南](https://developers.openai.com/api/docs/guides/image-prompting)

没有一个官方来源能证明存在适用于所有鞋款的“世界第一流程”。更可靠的结论是：先进做法把**商品身份、场景构图、风格**分开管理，把**融合质量**单独制作和检查，并用人工把关商品细节。

## 资料明确支持的事实

1. **参考图可以各司其职。** OpenAI 官方指南建议给每张输入图编号、说明它是商品、场景还是风格参考，并写清楚它们如何组合；Google 的官方图像文档也区分高保真对象、人物一致性和风格参考等用途。[OpenAI 提示指南](https://developers.openai.com/api/docs/guides/image-prompting) [Gemini 图像生成文档](https://ai.google.dev/gemini-api/docs/image-generation)
2. **遮罩只是在告诉模型“重点改哪里”，边界不绝对。** OpenAI 明确说明遮罩边缘不保证被精确遵守；多图输入时遮罩套在第一张图上。[OpenAI 图像生成 API 文档](https://developers.openai.com/api/docs/guides/image-generation)
3. **真实融合不只是颜色滤镜。** 《ObjectStitch》将物体合成中的重要部分列为几何/视角调整、颜色协调和阴影生成，并提出由扩散模型联合处理；另一篇 CVPR 工作 AnyDoor 说明物体身份与细节都要被表示，且为了融入场景，光照方向、姿势等局部变化会与外观保持发生取舍。[《ObjectStitch》](https://openaccess.thecvf.com/content/CVPR2023/html/Song_ObjectStitch_Object_Compositing_With_Diffusion_Model_CVPR_2023_paper.html) [《AnyDoor》](https://openaccess.thecvf.com/content/CVPR2024/html/Chen_AnyDoor_Zero-shot_Object-level_Image_Customization_CVPR_2024_paper.html)
4. **有专门的后期融合步骤。** Adobe Photoshop 的官方文档说明，Harmonize 会调整主体的光线、颜色、阴影和细节；其参考图工作流还能区分“单个主体”与“整张场景”，以及“替换选区”与“把对象放进选区并保留背景”。这证明成熟编辑流程会处理融合，不表示本项目已具备该工具或应购买它。[Adobe Harmonize 说明](https://helpx.adobe.com/photoshop/desktop/generative-ai/generative-ai-features-overview.html) [Adobe 参考图说明](https://helpx.adobe.com/photoshop/desktop/create-open-import-images/create-images/use-reference-images-for-consistent-results.html)
5. **要一轮只改一件事，并反复检查。** OpenAI 建议把上一次结果作为下一次编辑输入、一次提出一个变化，同时重述不能变的关键细节；并建议用真实工作样例检查商品几何、商品/身份保留、非目标区域和完整编辑序列。[OpenAI 图像提示指南](https://developers.openai.com/api/docs/guides/image-prompting) [OpenAI 图像评估工程指南](https://developers.openai.com/cookbook/examples/multimodal/image_evals)
6. **多视角参考数量不是“角度真实”的保证。** 当前商品盘点指出：TOPSTAR 5056 Beige 现有素材虽有多张，但真正不同的整鞋拍摄角度只有一个斜前视图；其它款图片不能证明 5056 的侧面、后跟或鞋底结构。[5056 素材复核](2026-09-27-topstar-model-selection.md) [5056 角度复核](2026-09-27-topstar-5056-angle-recheck.md)

## 建议的鞋类场景工作流

以下是基于上述资料与本项目约束的**推导建议**，不是任何模型对成片的承诺。

### 1. 先锁定“这双鞋到底是什么”

- 目标 SKU 的实拍图只负责证明鞋的外观；同款的其它实拍角度可以补充形状细节。
- 场景照片或构图草图只负责说明环境、机位和摆放；别的 SKU 图片只能参考拍法或氛围，不能借来证明目标鞋的结构。
- 提示里明确写图的角色，例如：“图 1 是目标鞋，保留其颜色、两条粘扣带、鞋头与鞋底；图 2 只参考场景和构图，不参考里面的鞋款。”
- 现有 5056 Beige 只有一个可靠整鞋方向，因此先让场景保留这个斜前角度；不让模型凭空把鞋转到侧面、背面、鞋底或脚上。要做这些画面，先取得同款对应角度或上脚实拍。生成模型能补像素，不等于补出了真实商品事实。

### 2. 让商品与场景一起设计，而不是“先画背景再贴图”

先定具体的一张摄影画面：鞋摆在什么表面、接触点在哪里、鞋占画面多大、相机从什么高度看、主光从哪边来、背景景深如何。随后用目标鞋参考与这张场景/构图参考做同一轮场景编辑，明确要求鞋底压住地面、透视和比例匹配、接触阴影及环境反光自然，场景光色方向一致。

如果场景底片已经选好，用选区/遮罩只重做鞋附近和需要的接触区域，尽量保住其余场景；但必须记住遮罩不是精准剪刀。若鞋本身发生形状或颜色变化，应判为商品保真失败，而不是继续靠提示词把改坏的鞋“修回去”。

另一条高保真路线是保留商品照片本身不被模型重绘，再对位置、尺度、地面接触、阴影和颜色做受控合成/协调。它可以减少鞋型漂移，但如果只保留原鞋像素并简单覆盖背景，仍会有贴图感；融合仍要单独验收。

### 3. 小步迭代，并分两道关验收

锁住原始商品参考和合格的场景底片；每轮只改一项，例如先修摆放/比例，再修光线/阴影，最后才调色调。每次沿用上一张结果，但重复写清哪些鞋的细节不可变化。若鞋款已明显漂移，从可信商品输入重新开始，不在漂移图上层层补丁。

验收分开做，不把“看起来漂亮”抵消“不是原款”：

- **商品关（硬性通过/不通过）：** 颜色、鞋型、鞋头、鞋底、粘扣带、材质/纹理和可见标记是否仍与目标商品一致；出现多/少部件或结构重画就退回。
- **场景关（逐项看）：** 鞋底是否真正落地；接触阴影方向和软硬是否合理；鞋的比例、机位与场景是否一致；是否有环境色影响；遮挡、焦点和景深是否自然；是否仍像抠图贴上去。
- 商品关未过时不交付；场景关未过时也不交付。机器或 AI 可指出疑点，但最终仍由人看图审核。

## 对这次问题的直接判断

目前默认“生成背景 + 程序叠透明鞋图”应从**场景最终成图**流程中撤下，最多保留为简单白底展示/内部排版用途。后续若重做场景候选，应优先测试“同款商品参考 + 明确的场景/机位参考 + 局部融合迭代 + 商品细节硬性复核”的路径。当前 5056 参考角度不足，因此在补到同款视角前，只应尝试不要求鞋子改变视角的自然静物场景；不能拿其它款的角度冒充 5056 的实拍。

这份结论不授权新生图、付费 API、改动现役 Runtime 或审核现有成图；官方 API 的能力描述也不代表 Codex 当前原生图片工具具有相同参数或保证。
