# Image Factory V1 使用教程

## 这是什么

飞书保存商品、素材和任务；Image Factory 负责按规则生图、等你审图、打包通过的图片。你只需要在本机工作台看图并做决定，不需要打开飞书底表，也不需要复制任何技术编号。

为什么要这样做：最难的不是“多画几张”，而是保证画的是对的商品、每张图有来源和版本、退回不会误交付、批准后还能找到使用结果。飞书保存业务资料，Engine 记住每一步，App 只让你做机器不能替代的看图决定。第一版因此只做审核和交付两页，不堆仪表盘或第二套素材库。

旧虚构童鞋演示已按要求清理。当前没有待审核任务；新 TOPSTAR 演示任务建立前，App 仍可打开空工作台，并清楚显示目前没有可审核图片。

## 打开工作台

1. 在项目文件夹双击 `dist/Image Factory.app`。
2. 点 App 里的“启动并打开审核工作台”。它会打开浏览器；使用期间保持 App 开着。
3. 浏览器顶部只有“待我审核”和“任务与交付”两个页面。

当前 App 只打开这台电脑上的工作台，不会重启生产、自动审核或消耗图片额度。以后确认好商品和本次额度后，它才会自动接收飞书表单任务；接单也不等于已经生图。不要把 App 单独移出项目文件夹，也不要把浏览器地址里的访问口令分享给别人。

## 图片调用次数和人工审核不是一回事

“最多 6 次图片调用”是给一次隔离演示设定的**尝试上限**：每次请求图片工具生成或修改一张图，都占一次；即使结果不好或失败，也不能把那次当作没发生。它不是“6 张图都通过”的意思，也不会替你点审核。通过或退回必须等图片出现后，由你在“待我审核”里逐张决定。旧虚构演示已经退役，它的额度不能挪给新 TOPSTAR 任务；新任务开始前，需另行明确这次愿意允许多少次尝试。

## 有新任务时如何审核

打开“待我审核” → 点第一张图看大图 → 点“通过”或“退回” → 在确认框里再确认。退回原因可以填写。对其余两张重复。**每张图都要由你自己决定**；刷新或双击不会替你做第二次有效审核。

这是 Demo：通过只表示你认可演示图的视觉效果，**不代表可用于真实上架或投放**。发现鞋型、颜色、字样、品牌等不对，就退回并写一句原因。系统会自动把图片版本、审核人、时间和适用规则绑定到你的决定；你不要到飞书底表补填。

审核后打开“任务与交付”。运行器完成后，这里可下载只包含已通过图片的 ZIP。三张都退回时不会生成交付 ZIP。若页面仍显示等待，不要重复点审核；先看下方故障说明。

## 打不开时

- 确认打开的是项目内的 `dist/Image Factory.app`，不是旧书签里的 `127.0.0.1` 地址；旧口令或端口可能已失效。
- App 打开后点“启动并打开审核工作台”，稍等浏览器自动出现。若 App 报连接或飞书验证错误，保留报错内容，不要反复提交审核。
- 备用入口是项目根目录的 `启动审核界面.command`。它和 App 都只负责打开审核界面，不是另一个审核系统。
- 技术人员可用 `查看图片工厂状态.command` 诊断 Runtime；普通用户不需要运行终端命令。若运行器显示错误或离线，先排查运行器，再等待“任务与交付”更新，不要自行改飞书审核表。

## 哪些事仍需要人

你负责确认商品资料、素材使用权和每张成图是否可接受。真实上架、投放与授权确认是独立的人类决定；Image Factory 不会因为一张 Demo 图片被通过就自动发布。

飞书里的“创建生图任务”表单现在有六项业务资料和“创建确认”一项；只有选“确认创建演示任务”才算明确要开工。但表单目前还未开放给普通用户：本机尚未设置新的 TOPSTAR 商品授权，商品选项和素材也未验收。请暂勿提交新任务；即使填完，也不能当作已经开工。现有审核与交付入口不受影响。
