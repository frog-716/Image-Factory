# Image Factory V1 用户指南

## 1. 启动程序

双击项目根目录的 `启动图片工厂.command`。窗口需要保持打开；本机 Runtime 会自动推进确定性节点，但原生生图仍需要在获授权的 Codex 会话中完成。

## 2. 选任务

在飞书“生产看板”中找到 `V1-DEMO-KIDS-*` 任务。任务已绑定虚构童鞋商品、Workflow 和四个提示词组件；不要修改 `RUN-001/002/003`。

## 3. 审图

候选图回写后，在飞书“审图台”为三张候选分别新建审核记录。选择“通过”或“驳回”，填写原因，勾选 `Demo视觉检查`、`仅限演示使用` 和 `人工确认`。程序不会代替人审批。

## 4. 拿图

审核全部完成后，保持运行器在线。它会自动导出只包含最新通过图片的 ZIP，并把交付和 Demo 模拟指标记入可追溯链路。全部驳回时结果为 `no_delivery`。

## 5. 暂停和继续

双击 `暂停图片工厂.command` 请求安全停止。再次双击 `启动图片工厂.command` 会从 SQLite 检查点继续，不会因重启而重画已接受节点。

## 6. 看错误

双击 `查看图片工厂状态.command`。`heartbeat.last_error` 是最后错误，`active_jobs[].job_file` 是当前原生图片任务。`waiting_worker` 表示 L1 Runtime 正常等待 Codex 原生生图，不代表后台生图失败。`unknown` 必须先人工对账，不得盲目重试。
